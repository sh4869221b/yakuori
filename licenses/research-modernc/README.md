# SQLite probe notice evidence

These archive texts and selected Linux source-header notice blocks are
retained for the earlier modernc dependency pins. Root notices for the current
SQLite and libc versions are retained in `verbatim-files/`; their source-header
notice blocks have not been re-audited. The CLI links SQLite. References in
generated headers do not necessarily govern the entirety of those files. No
module sources or SQLite probe executable are distributed in this preparation.

Some archive-only tests and platform headers have non-permissive or unusual
terms. Some referenced full legal instruments are not present in the upstream
archive. A future SQLite-linked binary/source-vendor release must resolve actual
scope and provide complete applicable texts and required source-delivery rights;
this notice collection is not a binary redistribution clearance.
